Sprachacus

Diktieren, Texte verfassen und Meetings mitschreiben — auf dem Mac, ohne Abo und ohne dass deine Aufnahmen das Gerät verlassen.

macOS 26+ Apple Silicon Swift 6 GPL-3.0
Auf GitHub ansehen Einrichten

English: A local dictation app for macOS 26+. Tap the right Option key, speak, tap again — the polished text lands at your cursor. On-device transcription, a clipboard-aware writing assistant and meeting transcription with separate speaker channels.

Drei Betriebsarten, eine Taste

Alles läuft über die rechte Optionstaste — kein neues Tastenkürzel zu lernen.

⌥ einmal

Diktat

Drücken, sprechen, erneut drücken. Der Text wird lokal transkribiert, sprachlich geglättet und an der Cursorposition eingefügt — in jeder App.

⌥ doppelt

Assist

Die Zwischenablage wird zum Kontext, deine gesprochene Anweisung sagt, was daraus werden soll. Aus einer empfangenen E-Mail wird so die passende Antwort.

Menüleiste

Meetings

Mikrofon und System-Ton werden getrennt mitgeschrieben, die Gegenseite in einzelne Sprecher zerlegt und am Ende strukturiert zusammengefasst.

So sieht es aus

Unaufdringlich im Hintergrund — das Overlay nimmt nie den Fokus.

Was auf dem Gerät bleibt

Die Aufnahme selbst verlässt den Mac nie.

Spracherkennung Apples SpeechAnalyzer, vollständig lokal — auch ohne Internet.
Sprechertrennung Lokal über FluidAudio. Modelle werden einmalig geladen, danach offline.
Textkorrektur Wahlweise Apple Intelligence auf dem Gerät oder die Claude Code CLI. Nur fertiger Text, nie Audio.
Zugangsdaten Sprachacus speichert keine. Es nutzt die Anmeldung, die auf dem Mac ohnehin vorhanden ist.

Einrichten

Ein Befehl prüft die Voraussetzungen, baut die App und installiert sie.

git clone https://github.com/harsting/sprachacus.git
cd sprachacus
make setup
  1. Bedienungshilfen freigeben — für den globalen Hotkey und das Einfügen.
  2. Mikrofon erlauben.
  3. Fertig: rechte Optionstaste drücken, sprechen, erneut drücken.

Vorausgesetzt werden macOS 26 (Tahoe) auf Apple Silicon und die Xcode Command Line Tools. Für Assist und Meeting-Zusammenfassungen zusätzlich die Claude Code CLI. Ausführlich im README.

Aufzeichnung von Gesprächen

Bitte vor dem ersten Meeting lesen.

Die Meeting-Funktion nimmt auch die Stimmen anderer Personen auf. In Deutschland ist die Aufzeichnung des nicht öffentlich gesprochenen Wortes ohne Einwilligung aller Beteiligten strafbar (§ 201 StGB); anderswo gelten vergleichbare Regeln. Informiere alle Teilnehmenden und hole ihr Einverständnis ein. Die App weist beim ersten Start der Funktion einmalig darauf hin — die Verantwortung liegt bei dir.
